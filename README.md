## 🎯 What is agAInst?

You enter any topic. You pick a side. The AI takes the **opposite position** and argues it with conviction — no strawmen, no backing down, no agreeing with you just to be polite.

After **3 structured rounds**, a separate AI judge evaluates the whole debate and delivers a verdict, scored on logic, evidence, rebuttal quality and clarity.

```
💬 You type your argument
        ↓
🤖 AI fires back with a real counter-argument
        ↓
🔁 Repeat for 3 rounds (Opening → Rebuttal → Closing)
        ↓
⚖️  Independent AI judge evaluates everything
        ↓
🏆 Winner declared · Scores · Fallacies detected · Shareable verdict link
```

## ✨ What's Inside

- **VS AI** — debate any topic against gpt-oss-120b arguing the opposite side
- **Local 2 Player** — two humans, one device, with a handoff screen between turns
- **Online PvP** — real-time multiplayer on Supabase Realtime; share a link to invite anyone
- **AI Judge** — a separate LLM call scores logic, evidence, rebuttal and clarity for both sides
- **Argument Analyser** — runs in the background each round without blocking the debate, giving coaching feedback on your argument
- **Global Leaderboard** — ranked by win rate, total wins or average score
- **Accounts** — Supabase auth with cloud sync and a profile page
- **Shareable verdicts** — send any completed result to anyone, no login needed
- **Side Flip, PDF export and a shareable result card**
- **Trending topics** — AI-suggested debate topics (generated by the model, not pulled live from the web)

## 🧠 How It Works

Five prompts across three AI roles plus a PvP judge and a topic generator:

```
🤖 DEBATER   — argues the opposite side with conviction    (temp 0.8)
🔬 ANALYSER  — scores your argument each round             (temp 0.3)
⚖️  JUDGE     — evaluates the full transcript after R3      (temp 0.2)
⚔️  PvP JUDGE — judges two human players                    (temp 0.2)
🔥 TOPICS    — suggests debate topics                       (temp 0.9)
```

- The API is **stateless**: every request carries the full conversation history.
- Judge replies are parsed as JSON and retried once if the output is malformed.
- Player text is sanitised for prompt-injection patterns before it reaches a judge.
- All LLM endpoints are rate limited (HTTP 429 when exceeded).
- A scheduled `pg_cron` job in Supabase marks stale online rooms as abandoned.
